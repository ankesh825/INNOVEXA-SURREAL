- **Interactive 360° 3D Studio**: Real-time Three.js WebGL rendering of the flagship Aloe Vera frosted jar with gold screw cap, "Inspect Layers" exploded view, glass condensation micro-droplets, and floating golden spores.
- **The Aloe Apothecary Lab**: Interactive fluid ripple viscosity simulator comparing Surreal Bioactive Aloe Gel vs Commercial Gel with real-time acoustic feedback.
- **7-Day Skin Hydration Slider**: Interactive before/after split slider demonstrating clinical barrier restoration.
- **Custom Hamper Studio**: Interactive 3D gift box visualizer with custom tier selection, occasion picker, and real-time pricing.
- **Skincare Ritual Guide & Quiz**: Diagnostic advisor tailoring morning, night, and weekend routines with 1-click bundle checkout.
- **Royal Cart & Slide-out Drawer**: Persistent cart drawer with quantity adjustments, free shipping progress bar, optional luxury wooden gift box, promo codes, and itemized WhatsApp checkout.
- **Verified Community Reviews**: Star rating showcase with an interactive modal to submit verified customer reviews saved to local storage.
- **Logistics Pincode Estimator**: Instant delivery checker offering same-day VIP farm dispatch for Indore (`452xxx`) and 24–48h express air dispatch nationwide.
- **Digital Certificate of Analysis**: Wax-sealed Batch #04 authenticity certificate detailing chemical purity and zero water dilution.

## 🛠️ Tech Stack

- **Frontend Framework**: React 19 + Vite 8
- **3D Graphics & Physics**: Three.js + WebGL
- **Styling**: Tailwind CSS v4 (Royal emerald `#173829` & Gold `#D4AF37`)
- **Sound Design**: Web Audio API Procedural Synthesizer
- **Icons**: Lucide React
- **Animations**: CSS Perspective 3D Transforms & Keyframe Motion

## 🚀 Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone <your-github-repo-url>
cd bizznovate

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Build production bundle in /dist
npm run build

# Preview production build locally
npm run preview
```
